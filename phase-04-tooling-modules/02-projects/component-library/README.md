# Component Library

A small reusable UI component library built with vanilla JavaScript and Vite.

## Components

- Button
- Badge
- Card

## What I Practiced

- ES Modules
- Reusable functions
- Creating DOM elements with JavaScript
- Passing callbacks into components
- Returning DOM elements from functions
- Reusing the same component with different data
- Vite project structure

## Commands

```bash
npm run dev
npm run build
npm run preview
```
